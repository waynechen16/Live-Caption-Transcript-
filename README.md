# Live Caption Transcript 即時字幕逐字稿

擷取網頁上的即時字幕（Microsoft Teams / Webex 自動偵測，其他網站可手動框選字幕區域），
自動去除重複與逐字修正，累積成含時間戳與發言者的逐字稿，可複製或下載成 .txt。

Chrome 和 Edge 都可以用（同一套檔案，不用修改）。

## 安裝方式（免上架，載入未封裝擴充功能）

1. 解壓縮這個 zip，得到 `caption-transcript` 資料夾。
2. 開啟擴充功能管理頁：
   - Chrome：網址列輸入 `chrome://extensions`
   - Edge：網址列輸入 `edge://extensions`
3. 打開右上角（Edge 在左下角）的「開發人員模式」。
4. 按「載入未封裝項目」（Load unpacked），選擇 `caption-transcript` 資料夾。
5. 完成。建議把它釘選到工具列，方便開會時點開。

## 使用方式

### Teams / Webex（自動偵測）
1. 進入會議，開啟會議內建的「即時字幕 / Live captions」功能（字幕要先顯示在畫面上）。
2. 點擴充功能圖示，按「開始擷取」。
3. 開完會（或隨時）點開 popup：可即時預覽、複製、或「下載 .txt」。

### 其他網站（手動框選）
1. 點擴充功能圖示 → 「框選字幕區域」。
2. 回到頁面，滑鼠移到字幕所在的區塊上（會有紅框提示），點一下選定。
3. 再點開擴充功能，按「開始擷取」。
4. 選過一次後，同一個網站會記住這個區域。

## 輸出格式

```
[14:03:22] 王小明: 那我們就先從上季的數字開始看。
[14:03:41] Wayne Chen: 好，我這邊分享畫面。
```

## 注意事項

- 字幕必須「顯示在頁面上」才抓得到——擷取的來源就是頁面上的字幕文字本身。
- 分頁重新整理或跳轉後，擷取會中斷，需要再按一次「開始擷取」（已累積的逐字稿不會消失，存在瀏覽器本機）。
- 同一時間建議只在一個分頁擷取，多個分頁同時擷取會混在同一份逐字稿裡。
- Teams / Webex 的介面改版可能導致自動偵測失效；此時用「框選字幕區域」手動指定即可。
- 所有資料只存在你的瀏覽器本機（chrome.storage.local），不會上傳到任何地方。
- 請注意會議錄存的合規性：擷取逐字稿前，依你所在環境的規範取得與會者同意。
